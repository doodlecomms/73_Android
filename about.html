About 73 Android

A free, hand-picked list of ham radio, SDR and off-grid apps for Android. Add them all at once with Obtainium, and they keep themselves up to date.

Why Obtainium

Many radio apps aren't on Google Play, or the Play version lags behind. Obtainium is a free, open-source app that installs and updates apps straight from where the developer publishes them. You get the official build, and Obtainium tells you when there's an update. No account is needed.

Where each app comes from

For every app we pick the best source we can, in this order:

  1. F-Droid

    We put F-Droid first because we want stable releases. F-Droid builds each app from its published source code and checks it before release. That means it can run a couple of weeks behind the developer's GitHub. We think that's a good trade for a build that's been reviewed and is known to work.

  2. The developer's own GitHub or website

    If an app isn't on F-Droid, we use the developer's official downloads, usually GitHub Releases or the app's own site. IzzyOnDroid, which hosts developers' official APKs as-is, counts here too. We follow stable releases only and skip betas and pre-releases.

  3. APKPure or Uptodown (last resort)

    Some apps are only published on Google Play. For those we use APKPure or Uptodown, which carry the same file that's on Play, unchanged and signed by the developer.

There's one exception: if an app has no stable Android release at all, we use the developer's nightly build and mark it in the list. SDR++ is the only one right now.

What we check before adding an app

  • The APK is signed by the app's developer.
  • It installs and updates through Obtainium on a real phone.
  • Google Play Protect doesn't block it on a current version of Android.
  • Obtainium shows the correct version, so you don't get false "update available" alerts.

Apps without a simple download link

A few developers don't post a plain "latest APK" link that Obtainium can follow. For those, the list uses small workarounds, such as reading the version from the file name on the developer's site. WoAD, APRSdroid, qFT8 and MeshCore are set up this way. They still come from the developer's official download, just found a different way.

We've contacted these developers to ask for a direct, stable APK link. When one adds it, we'll switch that app to the simpler setup. You don't need to do anything, because Obtainium picks up the change.

Why some apps are listed separately

A few apps can't be installed through Obtainium. Some are only on Google Play, like Ham2K PoLo, and ARDOP Winlink is a web app. These are under Install these separately on the setup page, with a direct link to each one.

See exactly what gets added

The whole list is one file, radio-apps.json. It shows the source and settings for every app, so you can review it before importing.
