# 73 Android

**Website: https://doodlecomms.github.io/73_Android/**

A curated set of ham radio apps for Android that you can install and keep updated in one go with [Obtainium](https://github.com/ImranR98/Obtainium). Open the website on your phone and follow the steps there.

- [How we pick sources](https://doodlecomms.github.io/73_Android/about.html)
- The app list Obtainium imports: [`radio-apps.json`](radio-apps.json)
